\## Git Workflow



This project uses a simple Git workflow:



1\. Create a new branch for a change.

2\. Make and test the change.

3\. Commit the change with a clear message.

4\. Push the branch to GitHub.

5\. Open a pull request.

6\. Merge the pull request after checking the changes.
